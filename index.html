About Me

The Engineer Behind the Code

I'm a Senior Flutter Developer based in India, currently consulting for Kotak Securities, where I own end-to-end account-opening workflows that serve thousands of users across web and mobile every day.

My journey began in telematics and payments internships, evolved through building white-label B2B platforms at Bizzsetu, and culminated in architecting complex fintech flows — KYC onboarding, RM-assist SDKs, joint-holder journeys, and audit-grade review systems — all running on a single modular Flutter codebase.

Beyond client work, I independently built Nabh AI — an Agentic AI Agricultural Coordination Platform, pairing a Flutter (BLoC) frontend with a FastAPI backend. It utilizes a stateful LLM backbone for intelligent, conversational interventions to mitigate crop stubble burning.

I care deeply about Clean Architecture, performance at scale, and writing code that teams can maintain for years. I'm also an active technical writer at fluttersolution.com, where I share rendering optimisation insights and architectural patterns.

Nabh AI

Agentic AI Agricultural Coordination Platform
Agentic AI Architecture: Engineered a Stateful Conversational Agent using a powerful LLM backbone to act as an autonomous agritech consultant, designed to intelligently mitigate agricultural stubble burning.
GenUI (Generative UI) Innovation: Pioneered a GenUI architecture where the LLM utilizes Function Calling to dynamically generate and stream Agentic UI components—such as real-time, interactive flutter_map hotspot overlays—directly into the chat interface based on parsed user intent.
Dynamic Context Injection: Orchestrated real-time prompt engineering by feeding live environmental data (via Open-Meteo API) and calculated financial subsidy metrics directly into the LLM’s system prompts to generate highly contextualized, persuasive, and localized messaging.
Context Window Management: Implemented robust memory handling on a FastAPI backend. Built systems to dynamically summarize and truncate chat history, effectively optimizing token limits while retaining crucial user context (e.g., location, crop type, acreage) across multi-turn sessions.
High-Performance Infrastructure: Built the Flutter (BLoC) frontend integration using Dio for low-latency streaming of the LLM's multimodal responses, fortified by comprehensive CI/CD pipelines for automated, reliable deployments.
